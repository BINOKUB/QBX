NOM
     echo - Afficher du texte ou rediriger vers un fichier

SYNOPSIS
     echo [texte] [> fichier | >> fichier]

DESCRIPTION
     Affiche la chaîne passée en argument sur la sortie standard.
     Supporte la redirection '>' (écrasement) et '>>' (ajout) vers le VFS.
