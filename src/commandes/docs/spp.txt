NOM
     spp - Supprimer un élément du système de fichiers

SYNOPSIS
     spp <nom_fichier>
     spp -r <nom_repertoire>

DESCRIPTION
     Supprime définitivement un fichier ou un dossier du stockage persistant.
     L'option '-r' est obligatoire pour détruire un répertoire.
