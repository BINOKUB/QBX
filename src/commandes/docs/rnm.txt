NOM
     rnm - Renommer un élément

SYNOPSIS
     rnm <ancien_fichier> <nouveau_fichier>
     rnm -r <ancien_rep> <nouveau_rep>

DESCRIPTION
     Renomme un fichier ou un répertoire dans le dossier courant.
     L'option '-r' est requise pour renommer un répertoire.
