NOM
     ls - Lister les fichiers et répertoires

SYNOPSIS
     ls [-l] [repertoire]

DESCRIPTION
     Parcourt et liste les éléments d'un répertoire dans le système de
     fichiers (VFS). Si aucun répertoire n'est spécifié, la commande liste
     le dossier courant. Permet d'inspecter une arborescence distante
     sans changer le répertoire de travail.

OPTIONS
     -l      Format long détaillant les permissions (drwxr-xr-x / -rw-r--r--),
             le nombre de liens, le propriétaire (qbx:qbx), la taille en octets,
             l'horodatage RTC et le nom de l'élément.
    -h      Utilisé avec -l, convertit les tailles d'octets brutes en unités
             lisibles (B, K, M).

EXEMPLES
     ls
     ls -lh
     ls docs
     ls -l /var
