NOM
     ls - Lister les fichiers et répertoires

SYNOPSIS
     ls [-l]

DESCRIPTION
     Parcourt et liste les éléments enregistrés dans le système de
     fichiers persistant (VFS sur /var).

OPTIONS
     -l      Format long détaillant les permissions (drwxr-xr-x / -rw-r--r--),
             le nombre de liens, le propriétaire (qbx:qbx), la taille en octets,
             l'horodatage RTC et le nom de l'élément.
